# 🏢 SmartSpace - Projeto Front-end

Este projeto foi desenvolvido como parte do meu aprendizado no curso de **Desenvolvimento Front-end**. O objetivo foi aplicar conceitos fundamentais de estruturação, estilização e responsividade para criar uma landing page profissional e moderna.

🔗 **Acesse o projeto aqui:** [SmartSpace Live](https://claudiamachado27.github.io/smartspace/)

---

## 🎓 Contexto do Projeto

O **SmartSpace** é o resultado de desafios práticos propostos durante o curso, onde o foco foi transformar um layout estático em uma página web funcional e adaptável a diferentes dispositivos.

### 🎯 Objetivos de Aprendizado:
* Aplicação de **HTML5 Semântico** para melhor acessibilidade e SEO.
* Domínio de **CSS3** para layouts complexos (Flexbox e Grid).
* Implementação de **Design Responsivo** (Mobile-First).
* Gerenciamento de versão e deploy via **GitHub Pages**.

---

## 🛠️ Tecnologias e Ferramentas

Para a construção deste projeto, utilizei as seguintes tecnologias:

* **HTML5:** Estrutura e conteúdo.
* **CSS3:** Estilização, variáveis CSS e animações sutis.
* **Google Fonts:** Para uma tipografia que comunica modernidade.
* **Git & GitHub:** Controle de versão e hospedagem.
